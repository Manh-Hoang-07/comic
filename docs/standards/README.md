# Tiêu Chuẩn Lập Trình (Coding Standards)

Chào mừng bạn đến với bộ tài liệu tiêu chuẩn code của dự án. Hãy tham khảo các mục dưới đây để đảm bảo code luôn sạch và đồng bộ.

---

## 📚 Danh Mục Quy Tắc

1.  **[Kiến Trúc & Phân Lớp](./01-architecture.md)**
    - Vai trò của Controller, Service, Repository.
    - Luồng đi của dữ liệu.

2.  **[Quy Tắc CRUD & Response](./02-crud-standards.md)**
    - Các thao tác chuẩn List, GetOne, Create, Update, Delete.
    - Cách thức Interceptor đóng gói JSON.

3.  **[Quy Tắc Đặt Tên](./03-naming-conventions.md)**
    - Đặt tên file, class, biến và hàm.

4.  **[Phong Cách Viết Code](./04-coding-style.md)**
    - DI, DRY, Fail-Fast, và các mẹo code sạch khác.

---

> [!TIP]
> Luôn tuân thủ các quy tắc này để hệ thống dễ bảo trì và mở rộng trong tương lai.
